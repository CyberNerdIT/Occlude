Step 3 — NVDEC decode + NVENC encode:

- cuda_io_available() gates everything: torchcodec importable + torch.cuda.is_available() + ffmpeg on PATH. Mac/CPU keep cv2; CUDA runs can use --require-cuda-io to make NVDEC/NVENC mandatory.

Step 4 — async pipelining (decode/process/encode):
- New occlude/pipeline/async_runner.py: run_async_pipeline() spins decode + encode workers on daemon threads with bounded queues (maxsize 2*B). Main thread runs the perception batch synchronously.
- NVDEC and NVENC share the GPU with SegFormer compute via dedicated codec engines (not SMs), so threading the CPU-side orchestration is what unlocks the overlap. Explicit CUDA streams skipped — they wouldn't help here because blur depends on perception output for the same frame.
- Source order preserved by FIFO queues: no reorder buffer needed.
- VideoProcessor.process dispatches to async on use_cuda_io, sync loop on Mac. Sync loop refactored to share the same _process_batch closure → single blur math definition.
